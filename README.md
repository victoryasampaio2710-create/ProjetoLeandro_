Sobre o projeto
O JP Acontece é um projeto acadêmico desenvolvido com HTML5 e CSS3, com o objetivo de apresentar
informações sobre turismo,história e cultura de João Pessoa – PB.

Objetivos
- Apresentar pontos turísticos.
- Valorizar a história da cidade.
- Divulgar eventos culturais.
  
Tecnologias utilizadas
- HTML5
- CSS
  
Estrutura do projeto
- index.html
- style.css
- imagens
